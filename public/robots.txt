# Note on /protocol/: those pages are the step-by-step rescue tunnel. They are
# kept OUT of the search index with <meta name="robots" content="noindex,follow">
# in Tunnel.astro. We deliberately do NOT Disallow them here: a crawler that is
# blocked never fetches the page and therefore never sees the noindex, which is
# how blocked URLs end up indexed as bare links. The meta tag is the stronger,
# more precise instruction and it is already in place.
#
# Note on the absent per-agent groups. There used to be 22 of them here, one
# per named search, AI-citation and AI-training crawler, and every one of them
# said nothing but "Allow: /". They came out on 2026-08-05 for two reasons:
#
#   1. THEY GRANTED NOTHING. The wildcard group below already allows every
#      crawler every path, so a named group that repeats it adds no permission.
#      It only adds a name.
#   2. THEY CREATED REAL AMBIGUITY. Cloudflare AI Crawl Control serves a
#      managed robots.txt that PREPENDS its own per-agent groups, and those can
#      carry Disallow lines. A crawler obeys the single most specific group
#      that matches its own name, so any agent named in both places had two
#      competing groups and the outcome depended on which one won. That is a
#      silent, untestable failure mode on the file that decides who reads the
#      site at all.
#
# So the AI access policy is decided in ONE place, the Cloudflare dashboard,
# where it can be changed without a deploy. This file states the site's own
# position and nothing else. Nothing here is disallowed to anyone.
