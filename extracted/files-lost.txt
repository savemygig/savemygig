Recovery_Mode
The night was rough.
The files may still be alive.
"Not readable" almost never means "gone". Most failed USBs still hold the data, the drive just can't present it anymore. What you do next decides whether it's recoverable.
⚠️ First: stop using the drive
Do not format it. Formatting destroys the recovery chances.
Do not keep re-plugging it into players, every mount can make it worse.
Put it aside until you're at a computer with recovery software.
Step 1 - Recovery software (works in most cases)
If the computer detects the drive at all (even without showing files), software can usually pull the music off it. Two tools I'd actually use:

Step 2 - If the drive is physically dead
No light, not detected anywhere, or it got hit/wet: software can't reach it. A recovery lab can, they open the drive and read the memory directly. Expensive, so only for irreplaceable files. When to use a lab →
Step 3 - Make this the last time
The DJs this never happens to aren't lucky, they run a system. It takes one evening to set up.
