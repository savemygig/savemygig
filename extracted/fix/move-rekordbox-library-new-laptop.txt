Library_Migration
NEW LAPTOP,
SAME LIBRARY
The mistake that destroys years of work: copying your music folder to the new laptop and re-importing it. Music survives, every cue, loop, grid adjustment and playlist dies. Use the built-in Library Backup instead.
The right way (30-60 min, mostly waiting)
Old laptop: Rekordbox → File → Library → Backup Library → choose "include music files" → target an external drive with enough space.
New laptop: install Rekordbox, log into the same Pioneer account, then File → Library → Restore Library from the external drive.
Verify: open your key playlists, load a few tracks, cues and grids should be exactly where you left them.
Re-export your gig USBs fresh from the new machine, both drives, and test one on a player before the next gig.
Cloud alternative
Rekordbox's Cloud Library Sync (with a subscription plan) can migrate cues and playlists through Pioneer's cloud, convenient for ongoing two-computer setups. For a one-time move, the local backup is faster, free, and doesn't depend on upload speeds.
While you're at it
This backup file is also your disaster insurance. Make one monthly; keep it off the gig bag.
